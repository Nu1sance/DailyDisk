# DailyDisk

DailyDisk 是一款 macOS 磁盘增长监测应用，帮助你了解：磁盘比上次多用了多少空间，哪些文件和目录贡献了增长，以及哪些空间变化暂时无法归因到普通文件。

## 功能

- **每天自动检查**：每天 05:00 完整检查一次；错过时间后，在符合条件的登录或唤醒时补查。
- **随时手动检查**：当天完成完整检查后，再次检查会尝试增量处理，必要时自动回退到完整检查。
- **查看变化来源**：展示文件增长、空间释放、未归因空间和 DailyDisk 自身占用；支持文件新增、删除、移动和体积变化。
- **趋势与历史报告**：浏览每日变化图表、主要增长与释放来源及目录汇总；支持分页查看全部变化记录，按增长、释放或仅逻辑大小变化筛选，并可导出报告摘要。
- **后台运行与真实进度**：查看检查阶段、计数和耗时；关闭窗口不会中断检查，保存开始前可以安全取消。
- **减少重复写入**：复用未变化的记录，自动清理符合条件的临时数据，并提供空间回收与诊断工具。
- **应用内更新**：在设置中点击“检查更新…”，下载并安装可用更新。安装期间暂停扫描，更新后恢复原有每日任务设置并保留历史。
- **隐私优先**：文件索引和报告保存在本机，无遥测上传。路径默认隐藏，通知只显示汇总信息。

首次检查用于建立基线，第二次成功检查开始显示相对变化。磁盘快照和系统管理的空间不一定能精确归因到某个文件；DailyDisk 会保留这部分差异，而不会给出虚假的文件来源。

## 下载与开始使用

适用于 **macOS 15 及以上**、使用内置 APFS 启动磁盘的 Mac。当前下载包面向 **Apple Silicon**；默认不检查外置硬盘和网络磁盘。

从 [最新正式版](https://github.com/Nu1sance/DailyDisk/releases/latest) 下载 Apple Silicon 安装包（DMG 或 ZIP），将 DailyDisk 放入“应用程序”。请只保留一份日常使用的应用。

**正式版 0.2.4（构建 19）已完成 Apple 公证。** 首次打开时 macOS 仍可能要求确认下载来源；完全磁盘访问与后台运行权限也需要按提示授权。已有测试版用户可直接使用“检查更新…”升级到正式版，之后继续接收稳定更新。

如果旧版打开设置时闪退，请从应用菜单发起“检查更新…”升级至 0.2.4，或获取上述发布页的新安装包。

1. 打开 DailyDisk，按提示在系统设置中授予“完全磁盘访问权限”，然后退出并重新打开应用。
2. 点击“启用每日检查”，如系统要求，允许 DailyDisk 后台运行。
3. 完成首次检查，之后在概览和历史中查看变化；通知权限可按需开启。

日常更新使用“检查更新…”即可。“高级操作”中的“暂停运行以手动替换应用”仅供手动安装时使用，完成或放弃替换后需点击“恢复运行”。更新会保留当前安装位置与本地历史；正常更新无需重置数据或重新配置每日任务。

## Homebrew 安装

```bash
brew install --cask nu1sance/tap/dailydisk
```

保留标准 `brew update`、`brew upgrade --cask nu1sance/tap/dailydisk`、`brew reinstall` 和 `brew uninstall`。使用 Homebrew 替换或卸载已有应用前，请先在高级操作中暂停运行并退出；更新后重新打开并点击“恢复运行”。卸载保留历史数据，应用内更新仍然可用。

默认安装到 `/Applications`；没有写入权限时可追加 `--appdir="$HOME/Applications"`。[详细说明](Docs/Homebrew.md)。
